# MiniTankForge Traffic Content Plan

Last updated: 2026-07-08

This document turns "traffic content" into a concrete workflow.

Goal:

1. Put MiniTankForge in front of tabletop, board game, micro armor, and WW2 miniature buyers.
2. Send each person to the most relevant MiniTankForge page.
3. Let the site answer scale, finish, contents, and trust questions.
4. Send ready buyers to Etsy for checkout.

Do not use Etsy messages, Etsy buyer conversations, Etsy order notes, or Etsy listing copy to move an Etsy-started purchase off Etsy. The site is for browsing, scale help, comparison, catalog discovery, and brand trust. Etsy remains the checkout path for Etsy buyers.

## Core Rule

Every post must have one job and one destination.

| Post Type | Main Job | Destination |
| --- | --- | --- |
| Scale comparison | Remove scale uncertainty | `https://minitankforge.com/scale-comparison.html` |
| Finish comparison | Show unpainted/base coat/painted options | `https://minitankforge.com/finish-guide.html` |
| Game-ready pack | Sell a complete use case | Exact set page first, Etsy listing second |
| Starter set | Sell a compact force | Exact set page first, Etsy listing second |
| Single tank spotlight | Create interest in a known vehicle | Exact tank page or Etsy listing |
| Detail proof | Prove print quality | Exact tank or set page |
| Tabletop use | Show the model in context | Exact set page or gallery |
| Packing/trust post | Reduce shipping concern | Reviews page, FAQ, or homepage |
| General brand post | Explain what MiniTankForge is | Homepage |

## Step 1: Open The Instagram Account

The first practical traffic-content action is to open a dedicated MiniTankForge Instagram account.

Use MiniTankForge as the public-facing brand. Do not use `Quali3DPrints` as the main Instagram identity. Quali3DPrints should remain the Etsy seller/trust identity, while MiniTankForge is the product brand buyers remember.

### Account Setup

4. `@minitankforge_ww2`

## Channel Map

Start with five channels. Do not add more until the first 4-week cycle is complete.

### Instagram

Purpose:
- Best visual channel for close-up photos, Reels, scale comparisons, and finished models.
- First traffic channel to open because the same assets can later be reused on Pinterest, YouTube Shorts, and Facebook posts.

What to post:
- 3 posts per week.
- Mix of photo posts, carousels, and short videos.

Best content:
- Macro tank detail.
- Scale lineup.
- Set contents.
- Finish comparison.
- Packing/order trust.

Link behavior:
- Put one clear link in bio.
- Rotate the bio link to the most recent campaign page if needed.
- Caption CTA should say where to go, for example: "Scale guide on MiniTankForge."
- Do not send every caption to the homepage. Match the caption to the exact guide, tank, set, or Etsy listing.

### Pinterest

Purpose:
- Long-term visual discovery. Pins can keep sending traffic long after posting.

What to post:
- 5 to 10 pins per week.
- Pin every useful product, scale, finish, and guide image.

Best content:
- Clean vertical product image.
- Scale comparison image.
- Finish comparison image.
- Starter set lineup.
- Game pack contents.

Link behavior:
- Each pin links directly to the matching page.
- Do not send every pin to the homepage.

### Facebook Groups

Purpose:
- Reach actual hobby buyers where discussion already happens.

What to post:
- 1 useful post per week.
- Only post where group rules allow maker/shop links.

Best content:
- Scale comparison help.
- Finish examples.
- "What scale works best for compact WW2 boards?"
- Non-sales discussion posts with a useful link when allowed.

Link behavior:
- Use a helpful guide link first.
- Use direct product links only in groups that clearly allow sales posts.

### BoardGameGeek

Purpose:
- Reach game-specific audiences, especially for game-ready packs.

What to post:
- Only game-relevant posts.
- Do not post generic shop promotion.

Best content:
- Pack contents for a specific game use case.
- Scale comparison for compact boards.
- Replacement/upgrade component examples.

Link behavior:
- Send to the exact set page, exact guide, or exact Etsy listing.
- Keep wording unofficial and do not imply publisher endorsement.

### YouTube Shorts

Purpose:
- Reuse the same short videos made for Instagram Reels.

What to post:
- 1 short per week.

Best content:
- 10 to 20 second model rotations.
- Set contents sweep.
- Scale lineup.
- Packing insert/order prep.

Link behavior:
- Description links to the exact site page.
- Use a direct Etsy link only for a product-specific short.

## Weekly Workflow

Use this every week.

### Monday: Pick The 3 Focus Products

Choose:
- 1 game-ready pack or starter set.
- 1 famous single tank.
- 1 guide topic, such as scale, finish, packing, or tabletop use.

Write these down:

```text
Week:
Product 1:
Product 2:
Guide topic:
Main destination link:
Secondary Etsy link:
```

### Tuesday: Prepare Assets

Prepare:
- 1 short video.
- 2 square or 4:5 images for Instagram.
- 3 vertical images for Pinterest.
- 1 useful community post draft.

Use existing site photos first. Shoot only what is missing.

### Wednesday: Write Captions

Every caption uses this structure:

```text
Hook:
What it shows:
Why it matters:
Destination:
```

Example:

```text
Hook: Same kind of WW2 tank miniature, different tabletop scales.
What it shows: 1:160, 1:180, 1:200, 1:250, and 1:285 options.
Why it matters: Scale is the hardest thing to judge online, especially for compact board games.
Destination: Full scale guide on MiniTankForge.
```

### Thursday: Publish

Post:
- 1 Instagram post or Reel.
- 3 to 5 Pinterest pins.
- 1 YouTube Short if a video exists.

Schedule or draft:
- Next Instagram post.
- Next Pinterest pins.

### Weekend: Community Post Or Replies

Do one:
- Post a useful scale/finish guide where allowed.
- Reply to a relevant thread with helpful context.
- Share a product only if that community clearly allows shop/product links.

## Weekly Tracking

Record this every Monday.

```text
Week:
Posts published:
Instagram posts:
Pinterest pins:
YouTube Shorts:
Community posts:
Top destination link:
MiniTankForge visits from social/referral:
Etsy outbound clicks from site:
Etsy orders that mention site/social:
Best post:
Worst post:
Next action:
```

Decision rules:

- If a post gets saves, comments, or link clicks, make a second version with a different tank or set.
- If a post gets views but no clicks, improve the CTA and send it to a more specific page.
- If a community post gets useful comments, reply and turn the answers into the next post.
- If a post causes Etsy favorites/orders, reuse that format within 7 days.
- If a channel produces no useful traffic after 4 weeks, reduce it and move effort to the best channel.
