# Etsy Listing Packet — One-Off Hand-Painted Tank Collection

Prepared: 2026-09-04

Use one listing with a `Tank choice` variation. Each choice has quantity 1 and costs EUR 25.00.

Do **not** add `All ten` as an ordinary variation. Etsy will not automatically link that bundle's inventory to the ten individual choices, so the same physical tank could be sold twice. Instead, invite the buyer to message first; if all ten remain available, make a reserved EUR 200.00 listing and deactivate the individual listing.

## 10. Full-collection sale procedure

When someone asks for all ten:

1. Check that every variation still has quantity 1.
2. Deactivate this individual-tank listing temporarily.
3. Duplicate it into a reserved listing titled `Reserved – Complete Hand-Painted Tank Collection – 10 Models`.
4. Remove variations, set quantity 1, and set price to EUR 200.00.
5. Send the reserved listing link to the buyer.
6. If the bundle does not sell, reactivate the individual-tank listing.

After the individual listing is published, copy its exact Etsy URL into the website's Hand-Painted page and replace both pending buttons that refer to this collection.
