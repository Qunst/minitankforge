Set overview

What this set is for

This set gives you six German experimental or late-war concept vehicles in one group: E-100, E-25, E-50, E-75, Maus, and Panzer VII Loewe. It is the set to choose when you want unusual German armor rather than the standard battlefield lineup. The vehicles lean heavily into super-heavy and paper-project designs, so it has more of a what-if collection feel.
