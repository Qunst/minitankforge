Set overview

What this set is for

This set gives you six Soviet WW2 tank destroyers and assault guns in one group: SU-76, SU-85, SU-100, SU-122, ISU-122, and ISU-152. It is a good pick if you want Soviet support vehicles rather than a tank-only lineup. The mix moves from smaller SU vehicles into the heavier ISU assault guns, so it has a clear support and breakthrough feel.
