Game upgrade

Physical pieces for Lone Sherman

This pack is an unofficial 3D printed accessory set for players who want physical pieces for Mike Lambo's Lone Sherman rather than relying only on printed counters. The pack is built around the Sherman, German armor, infantry, and truck pieces used for the European game setting, with versions for the full pack, tanks only, support pieces, or an extra Sherman.

Scale note

Fixed 1:250 game scale

Fixed at 1:250 so the vehicles have a little more table presence while staying practical for Lone Sherman play. This pack is not meant to be mixed with the variable-scale starter sets.
