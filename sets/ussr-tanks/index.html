Set overview

What this set is for

This set gives you six Soviet WW2 tanks in one group: T-34, T-34/85, KV-2, IS-1, IS-2, and IS-3. It is the cleanest Soviet choice if you want tanks only, with no assault guns or support vehicles included. The lineup moves from the classic T-34 family into heavier breakthrough tanks, so it works well as a compact Soviet armor shelf or tabletop group.
