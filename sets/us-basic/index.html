Set overview

What this set is for

This set gives you six Allied WW2 vehicles in one group: M18 Hellcat, M3 Lee, M5A1 Stuart, Pershing, Sherman, and Sherman Firefly. It is a balanced American starter choice if you want light armor, medium tanks, a tank destroyer, and a heavier late-war vehicle together. The Sherman and Firefly make it easy to anchor the set in familiar Allied armor.
